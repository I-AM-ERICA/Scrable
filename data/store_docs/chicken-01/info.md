# 바삭치킨 가게 정보

※ 실험용 가상 매장입니다.

## 기본 정보
- 업종: 치킨
- 영업시간: 매일 16:00~02:00 (마지막 주문 01:30), 매주 화요일 휴무
- 매장 전화: 영업시간 중에만 받습니다. 금·토 19:00~21:00에는 주문이 몰려 연결이 늦을 수 있습니다.

## 메뉴
- 후라이드, 양념, 간장마늘
- 반반 선택 시 1,000원 추가, 순살 변경 시 2,000원 추가
- 치킨무 1개 기본 제공. 콜라는 별도 판매(1.25L 2,500원)이며 기본 제공하지 않습니다.
- 양념소스 추가 500원 (요청사항이 아니라 메뉴 옵션에서 선택해야 합니다)
- 하루 준비한 닭이 소진되면 영업시간 중이라도 주문을 받지 않거나 취소될 수 있습니다.

## 조리·배달
- 조리 시간은 보통 20~30분이며, 금·토 저녁에는 1시간 이상 걸릴 수 있습니다.
- 배달은 배달앱 배달기사가 진행합니다. 문 앞 배송·연락 방식은 배달앱 요청사항을 따릅니다.
- 포장 주문 시 2,000원 할인됩니다.
- 누락·오배송·조리 상태 문제는 배달앱 고객센터 또는 매장 전화로 알려주시면 확인 후 안내드립니다.
- 환불·재조리 여부는 확인 후 개별 안내하며, 리뷰 답글에서 확정하지 않습니다.

## 리뷰 이벤트
- 주문 시 리뷰 작성을 약속하면 치즈볼을 서비스로 드립니다. 별점이나 내용은 자유롭게 써 주시면 됩니다.
