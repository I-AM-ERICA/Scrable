# 든든국밥 가게 정보

※ 실험용 가상 매장입니다.

## 기본 정보
- 업종: 국밥·한식
- 영업시간: 월~토 07:00~21:00 (마지막 주문 20:30), 매주 일요일 휴무
- 매장 전화: 영업시간 중에만 받습니다. 점심(11:30~13:00)에는 연결이 늦을 수 있습니다.

## 메뉴
- 돼지국밥, 순대국밥, 수육백반
- 특(고기 추가) 2,000원 추가, 공깃밥 추가 1,000원
- 다대기(양념)는 따로 담아 드려 맵기를 직접 조절할 수 있습니다. 추가 다대기는 요청사항에 적어 주세요.
- 김치·깍두기 기본 제공, 추가는 요청사항에 적어 주세요.

## 배달·포장
- 국물은 밀봉 용기에 담고 랩으로 한 번 더 감싸 보냅니다.
- 배달은 배달앱 배달기사가 진행하며, 거리와 주문량에 따라 시간이 달라질 수 있습니다.
- 누락·오배송·음식 상태 문제는 배달앱 고객센터 또는 매장 전화로 알려주시면 확인 후 안내드립니다.
- 환불·재조리 여부는 확인 후 개별 안내하며, 리뷰 답글에서 확정하지 않습니다.

## 리뷰 이벤트
- 주문 시 리뷰 작성을 약속하면 음료수 1캔을 서비스로 드립니다. 별점이나 내용은 자유롭게 써 주시면 됩니다.
