# 아침빵집 가게 정보

※ 실험용 가상 매장입니다. 2단계 학습용 매장이며 테스트 매장과 겹치지 않습니다.

## 기본 정보
- 업종: 베이커리
- 영업시간: 월~토 07:30~20:00, 매주 일요일 휴무
- 매장 전화: 영업시간 중에만 받습니다.

## 메뉴
- 소금빵, 크루아상, 식빵, 단팥빵, 조각케이크
- 모든 빵은 당일 아침에 굽고 당일에만 판매합니다. 소금빵과 크루아상은 오후에 품절되는 경우가 많습니다.
- 홀케이크는 2일 전까지 매장 전화로 예약해 주셔야 합니다.
- 알레르기 안내: 모든 제품은 같은 공간에서 밀·우유·계란·견과류를 함께 사용해 만듭니다. 특정 성분을 완전히 뺀 제품은 없습니다.

## 배달·포장
- 배달 최소 주문 금액 15,000원
- 배달은 배달앱 배달기사가 진행합니다. 크림이 들어간 제품은 배달 중 모양이 흐트러질 수 있습니다.
- 누락·오배송·제품 상태 문제는 배달앱 고객센터 또는 매장 전화로 알려주시면 확인 후 안내드립니다.
- 환불·교환 여부는 확인 후 개별 안내하며, 리뷰 답글에서 확정하지 않습니다.

## 리뷰 이벤트
- 주문 시 리뷰 작성을 약속하면 미니 마들렌 1개를 서비스로 드립니다. 별점이나 내용은 자유롭게 써 주시면 됩니다.
