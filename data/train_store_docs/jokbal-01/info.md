# 한마음족발 가게 정보

※ 실험용 가상 매장입니다. 2단계 학습용 매장이며 테스트 매장과 겹치지 않습니다.

## 기본 정보
- 업종: 족발·보쌈
- 영업시간: 매일 15:00~01:00 (마지막 주문 00:30), 설날·추석 당일만 휴무
- 매장 전화: 영업시간 중에만 받습니다.

## 메뉴
- 족발(앞다리), 보쌈, 족발·보쌈 반반 (중 / 대)
- 막국수는 별도 메뉴(7,000원)이며 기본 구성에 포함되지 않습니다.
- 쌈채소·새우젓·마늘·쌈장 기본 제공. 쌈채소 추가는 2,000원(메뉴 옵션에서 선택)입니다.
- 족발은 매일 매장에서 삶습니다. 식은 족발은 전자레인지에 30초 정도 데우면 부드러워집니다.

## 배달·포장
- 배달은 배달앱 배달기사가 진행합니다. 주말 저녁에는 시간이 더 걸릴 수 있습니다.
- 누락·오배송·음식 상태 문제는 배달앱 고객센터 또는 매장 전화로 알려주시면 확인 후 안내드립니다.
- 환불·재배달 여부는 확인 후 개별 안내하며, 리뷰 답글에서 확정하지 않습니다.

## 리뷰 이벤트
- 주문 시 리뷰 작성을 약속하면 주먹밥 1개를 서비스로 드립니다. 별점이나 내용은 자유롭게 써 주시면 됩니다.
